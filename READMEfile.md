🩸 RaktSetu – Blood Bank Management System

RaktSetu is an android mobile application designed to manage blood donors, hospital requests, and blood stock efficiently. It provides a centralized platform for real-time tracking and management of blood availability.

🚀 Features
	•	Donor Registration and Management
	•	Hospital Blood Requests (Urgent/Fulfilled)
	•	Search by Blood Group and City
	•	Admin Dashboard with Live Statistics
	•	Low Stock Alerts
  
🗄️ Database
The system uses structured SQL tables:
	•	Donors
	•	Hospitals
	•	Blood Requests
	•	Inventory

Designed using normalization principles to ensure data consistency.

🛠️ Tech Stack
	•	Frontend: Flutter
	•	Database: SQL

📱 Build APK

flutter build apk --release

APK Path:

build/app/outputs/flutter-apk/app-release.apk

🎓 Conclusion

RaktSetu demonstrates practical implementation of DBMS concepts through a real-world application for efficient blood donation and request management.
